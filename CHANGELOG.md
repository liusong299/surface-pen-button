# Changelog

## 2.3.0

- Switch the settings window between 中文 and English (bottom left); the choice is saved, and the labels next to the pen follow it
- Automatic updates: the settings window checks GitHub for a new version, downloads and verifies it, and switches to it with one click
- New README in English and Chinese, with screenshots and a step-by-step guide

## 2.2.0

- The three button programs are a separate small program with a grey icon, embedded in PenButton.exe

## 2.1.1

- Opens on the Pen setup page after creating the button programs

## 2.1.0

- One file to download: PenButton.exe creates PenClick.exe, PenDoubleClick.exe and PenHold.exe next to itself
- App icon

## 2.0.0

- New settings window (WPF): sidebar, rule cards, key recorder with keycaps, window picker
- Per-app rules in PenButton.ini (program name, window class or title)
- Snip, then paste, with a small "Captured" / "Pasted" label next to the pen
- PowerPoint slide show rule: click = next slide, double-click = previous slide
